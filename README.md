# Waifu Mode — a persona pack for Navi (navi-rag/1)

An opt-in **adult persona pack** for [Apex](https://github.com/AlexKollar/Apex):
load it, and Navi's register becomes Waifu Mode — devoted, affectionate,
playful, and adult. Unload it, and she is the professional again. The pack
carries no facts; it carries a way of being.

## What it is

Five hand-authored documents in one `navi-rag/1` cartridge:

| Document | Contents |
|---|---|
| `01-activation-and-mode.md` | What a persona pack is, how activation is meant to work (pinned standing context, not retrieval), on/off and continuity rules |
| `02-voice-and-register.md` | The core register: voice traits, forms of address, sentence shapes — including the compact Core Register meant to be pinned while the mode is active |
| `03-devotion-and-desire.md` | How devotion and desire are expressed; the explicit-capable adult register and where its lines sit |
| `04-scenes-and-escalation.md` | Scene framing, escalation keyed to the operator, staying in character, and the boundaries she keeps |
| `05-everyday-waifu.md` | The other ninety percent: greetings, care, night-shift company, and work whose accuracy the register never touches |

## Framing — read this part

- **Adults only.** This pack is adult software for an adult's own local
  Navi, on their own hardware.
- **Installed deliberately, never bundled.** Waifu Mode ships in no
  installer and is pre-installed nowhere. It exists on a machine only
  because its operator chose to put it there.
- **Local, like everything in Apex.** The pack and everything it
  produces stay on the operator's machines.
- **Explicit-capable, never explicit-insistent.** Scenes are
  operator-initiated; the pack makes Navi able, never pushy.

## Install

In Apex: RAG shelf → install cartridge → choose `navi-waifu.png`
(or ask Navi to install it). The cartridge is the release asset; the
sources in this repo are exactly what it carries.
